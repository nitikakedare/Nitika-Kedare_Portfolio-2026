Assignment Brief:
The assignment involved designing a tabletop game in groups of 5, focusing on developing engaging gameplay mechanics and a clear rule system. The game concept was required to be rooted in an Indian context, encouraging themes or narratives inspired by Indian culture and social experiences.

Concept Ideation:
During the ideation phase, we explored culturally familiar situations that could translate into playful social interaction. This led us to the idea of turning the dramatic and humorous process of arranged matchmaking into a competitive card game.

Card Design

Manual Design

GAME
CONCEPT

Our game, “Band Baaja Breakdown”, is a card-based party game set in the lively world of desi arranged marriages. Players present themselves as potential matches using Fact and Perk cards, while strategically using Gossip cards to disrupt other players. One player takes on the role of the “Proposal,” awarding Roses across rounds based on the players’ cards and performances. After four rounds of negotiation, drama, and strategy, the player with the highest number of Roses and Proposal cards wins the game.

MOBILE GAME DESIGN

Assignment Brief:
The assignment involved designing and developing a simple mobile game using basic game mechanics and introductory coding principles. The focus was on ideating an arcade-style game and translating the concept into a playable prototype with core interactive elements.

GAME
CONCEPT:

For this project, I developed "Space Drift", an arcade-style mobile game centered around navigating a drifting spacecraft through space. Created my first game using the Unity game development platform, the project allowed me to explore basic game design and coding workflows. The visual direction uses a minimal cosmic environment with obstacles to create a fast-paced and engaging gameplay experience. The game interface includes a start screen, restart functionality, and a score manager to track the player’s progress, reinforcing the classic arcade gameplay loop.
